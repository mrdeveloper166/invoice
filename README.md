# 🧾 Invoice Management System

A PHP-based Invoice Management System designed to create, manage, and generate professional invoices. The project uses PHP and MySQL with a responsive frontend interface.

## ✨ Features

* Create and manage invoices
* Customer management
* Product/service management
* Invoice calculations
* Tax and discount support
* Invoice details and history
* Professional invoice layout
* Responsive design
* MySQL database integration
* PHP-based backend

## 🛠️ Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/mrdeveloper166/invoice.git
```

2. Move the project to the XAMPP `htdocs` folder.

3. Start **Apache** and **MySQL** from XAMPP.

4. Create a database in **phpMyAdmin**.

5. Import the project's SQL file if available.

6. Update the database connection settings.

7. Open the project:

```text
http://localhost/invoice/
```

## 🎯 Project Purpose

This project demonstrates PHP and MySQL development for invoice generation, customer management, database operations, and business billing workflows.
